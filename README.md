# 그때또다시 · 모바일 영상 미리보기

새 휴먼 감동 5편과 기존 5편 종소리 수정본의 모바일 검토 사이트입니다.

- 원본 최종 MP4를 재인코딩하지 않고 그대로 제공합니다.
- H.264/AAC, playsinline, 기본 재생 컨트롤, 동시 재생 방지.
- 유튜브 게시 및 기존 게시물 변경은 포함하지 않습니다.
- 검색 제외 요청은 접근 제한 기능이 아닙니다. 저장소와 사이트는 공개입니다.
- 실제 원본 사용권 미확인 판정은 유지합니다.
- 제작 원본, 인증 자료, 음성 API 응답, 계정·내부 검수 기록은 포함하지 않습니다.

GitHub Pages는 main 브랜치 루트에서 배포합니다.
